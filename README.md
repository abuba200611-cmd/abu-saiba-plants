# أبو صيبع للنباتات والزهور — موقع تسويقي

موقع تسويقي بصفحة واحدة (HTML/CSS/JS نقي، بدون build) لمحل نباتات وزهور حقيقي في مملكة
البحرين — "أبو صيبع للنباتات والزهور" (مؤسسة أبو صيبع للنباتات والزهور، تأسست 2004).

## التشغيل محلياً

أسهل طريقة: **دبل كليك على `تشغيل_الموقع.cmd`** — يفتح المتصفح تلقائياً ويطبع رابط
الجوال على الشاشة.

أو يدوياً:
```bash
node .preview-server.js
```
يفتح على `http://localhost:8125`. أو عبر إعداد `abu-saiba-plants` في
`C:\Users\Aisha\.claude\launch.json` (منفذ 8125).

### فتح الموقع من الجوال (مهم)
`localhost` **ما يشتغل من الجوال أبداً** — لازم عنوان شبكة الواي فاي للكمبيوتر:

**http://192.168.33.32:8125**

الشروط:
1. جوالك وكمبيوترك على **نفس شبكة الواي فاي بالضبط** (مو داتا الجوال، ومو شبكة ضيوف
   منفصلة).
2. الخادم لازم يكون **شغّالاً وقت الفتح** — شغّلي `تشغيل_الموقع.cmd` وخليه مفتوحاً.
3. لو تغيّر IP الكمبيوتر (شبكة جديدة مثلاً)، أعيدي تشغيل `Get-NetIPAddress` بباوورشيل
   للحصول على العنوان الجديد.

هذا الرابط **مؤقت** ومرتبط بجهازك وشبكتك — للحصول على رابط دائم يفتح من أي مكان وبأي وقت
(حتى لو جهازك مطفي)، لازم نشر فعلي (Netlify أو غيره).

## قيم مؤقتة (Placeholders) — لازم تحديثها قبل النشر الفعلي

### 1) الصور — **الأهم**
كل صور الموقع (الهيرو، من نحن، التصنيفات، المنتجات، الكاروسيل، المعرض) هي **صور ستوك من
Unsplash** (ترخيص Unsplash المجاني للاستخدام التجاري)، **وليست صوراً حقيقية من المحل** —
لأن معرض صور خرائط قوقل وحساب إنستقرام الرسمي تعذّر الوصول لهما تلقائياً في هذي الجلسة
(إنستقرام حجب التصفح الآلي، ومعرض خرائط قوقل لم يُحمَّل بالكامل). هذي أهم نقطة تحتاج
تحديث قبل أي نشر فعلي — استبدلي الملفات التالية بصور حقيقية من المحل (نفس الأسماء، نفس
المسارات):

```
assets/img/hero.jpg              (1920×1080)
assets/img/about.jpg             (1200×1000)
assets/img/cat-indoor.jpg        (800×800)
assets/img/cat-outdoor.jpg       (800×800)

```

أفضل مصدر للصور الحقيقية: حساب إنستقرام `@abusaibaplants` (فيه مئات الصور الحقيقية) —
افتحيه من جوالك واحفظي 15-20 صورة بدون أشخاص فيها وأرسليها لي لأستبدلها، أو استبدليها
بنفسك بنفس الأسماء بالضبط.

### 2) الأسعار
كل الأسعار في قسم "منتجات مميزة" **استرشادية بالكامل** (لا تعكس أسعار المحل الحقيقية):
مونستيرا 8.500 د.ب، صبار 3.000 د.ب، أوركيد 12.000 د.ب، نخلة 15.000 د.ب، باقة ورد
10.000 د.ب، صندوق ورد 18.000 د.ب. حدّثيها في `index.html` (ابحثي عن `class="price"`).

### 3) المنتجات نفسها
الـ6 منتجات المعروضة أمثلة تمثيلية بناءً على خدمات المحل الموصوفة رسمياً (نباتات داخلية/
خارجية، باقات، هدايا) — مو قائمة منتجات فعلية من المحل. حدّثيها بمنتجات حقيقية إذا توفرت
قائمة أسعار من صاحب المحل.

### 4) النطاق (Domain)
`https://abu-saiba-plants.example.com` مستخدم في: `index.html` (canonical، Open Graph)،
`robots.txt`، `sitemap.xml`. استبدليه بالنطاق الحقيقي بعد الشراء/النشر.

### 5) وسائل الدفع (قسم الأسئلة الشائعة)
إجابة سؤال "ما وسائل الدفع المتاحة؟" استرشادية بالكامل (نقد/بطاقة) — أكّديها مع المحل.

### 6) عدد المتابعين على إنستقرام
"82k+" في عدّاد الإحصائيات وشارة الهيرو رقم حقيقي وقت كتابة هذا التقرير (2026-07-27) لكنه
يزيد باستمرار — حدّثيه دورياً أو اجعليه أعم ("+80 ألف").

## التقنية

- HTML/CSS/JS نقي، بدون أي build tool أو تبعيات خارجية عبر npm.
- RTL كامل (`dir="rtl"`)، خطوط El Messiri (عناوين) + Tajawal (نصوص) عبر Google Fonts.
- وضع داكن يدوي (`data-theme` + localStorage) مع سكربت رأس يمنع الوميض عند التحميل.
- SEO: `robots.txt` + `sitemap.xml` + `schema.org` (`FlowerShop` + `FAQPage`) + Open Graph
  كامل بصورة 1200×630.
- خادم معاينة محلي: `.preview-server.js` (Node، بدون تبعيات) على المنفذ 8125.
- كل الحركات تحترم `prefers-reduced-motion`.

## نتائج فحص الجودة (website-qa-checklist)

تم تنفيذ بوابة الفحص كاملة فعلياً عبر أدوات المتصفح (لا قراءة كود فقط): تسلسل عناوين
h1→h2→h3 سليم (h1 واحد فقط)، لا صور بدون alt، لا معرّفات مكررة، كل الحقول لها تسميات،
اختبار حقيقي عبر `elementFromPoint` لكل الأزرار الرئيسية، فحص `[hidden]` بدون تعارض
`display`، صفر تمدد أفقي على 1280px و375px (بعد إصلاح خلل حقيقي في قائمة الجوال — راجع
سجل الدروس بسكِل `website-qa-checklist` لتفاصيل الإصلاح)، فلترة المنتجات، اللايت بوكس
(حبس تركيز + إرجاع فوكس + تنقّل لوحة مفاتيح)، الأكورديون، الكاروسيل، ونماذج واتساب (تحقق
فعلي من رسائل واتساب المُولَّدة) — كلها اختُبرت ونجحت.
